- B2B SaaS companies ($1M-$50M ARR)
- Series A-C funded or profitable bootstrap
- Remote-friendly or hybrid
- Actively hiring or growing


- Generic connection requests

#### SEO
**Strategy**: Optimize your content and website for search engines

**Keyword Research:**
- **Target Keywords**: B2B SaaS content strategy, content marketing for SaaS, SaaS content ROI, etc.
- **Search Volume**: Focus on keywords with 100-1,000 monthly searches
- **Difficulty**: Target low to medium difficulty keywords
- **Intent**: Focus on commercial and informational intent

**On-Page SEO:**
- **Title Tags**: Include primary keyword (50-60 characters)
- **Meta Descriptions**: Include primary keyword (150-160 characters)
- **Header Tags**: Use H1, H2, H3 for structure and keywords
- **Content**: Include primary and secondary keywords naturally
- **Images**: Use descriptive file names and alt text
- **Internal Linking**: Link to other relevant pages on your site
- **External Linking**: Link to authoritative external sources

**Technical SEO:**
- **Mobile-Friendly**: Ensure your site is responsive
- **Site Speed**: Optimize for fast loading (use Google PageSpeed Insights)
- **SSL Certificate**: Use HTTPS for security
- **Sitemap**: Submit to Google Search Console
- **Robots.txt**: Configure for search engines
- **Structured Data**: Add schema markup for rich snippets

**SEO Tips:**
✅ **Focus on long-tail keywords** (easier to rank for, higher intent)
✅ **Optimize for featured snippets** (answer common questions concisely)
✅ **Build backlinks** (guest posts, partnerships, directories)
✅ **Update old content** (refresh and optimize existing posts)
✅ **Track rankings** (use Google Search Console, Ahrefs, or SEMrush)

❌ **Avoid**:
- Keyword stuffing (unnatural keyword usage)
- Ignoring technical SEO
- Not tracking rankings
- Focusing only on high-volume keywords
- Neglecting user experience

**SEO Metrics:**
- **Organic Traffic**: 1,000-5,000 visitors/month
- **Keyword Rankings**: Top 10 for 20-50 keywords
- **Backlinks**: 10-20 new backlinks/month
- **Click-Through Rate (CTR)**: 3-5% (from search results)

## Lead Qualification Framework

### BANT Framework
Use the **BANT** framework to qualify leads:
- **Budget**: Do they have the budget for your services?
- **Authority**: Are they the decision-maker or can they influence the decision?
- **Need**: Do they have a need for your services?
- **Timeline**: Do they have a timeline for addressing their need?

### Lead Scoring
Assign points to each qualification criterion:

| Criterion | Points | Notes |
|-----------|--------|-------|
| **Budget** | | |
| Has $5K+/month budget | 10 | Ideal |
| Has $3K-$5K/month budget | 5 | Potential |
| Has <$3K/month budget | 0 | Not a fit |
| **Authority** | | |
| Decision-maker (VP of Marketing, CMO) | 10 | Ideal |
| Influencer (Marketing Manager, Director) | 5 | Potential |
| Individual contributor (Specialist, Coordinator) | 0 | Not a fit |
| **Need** | | |
| Actively looking for content strategy help | 10 | Ideal |
| Struggling with content marketing | 5 | Potential |
| Happy with current content strategy | 0 | Not a fit |
| **Timeline** | | |
| Needs help within 30 days | 10 | Ideal |
| Needs help within 90 days | 5 | Potential |
| No urgent timeline | 0 | Not a fit |
| **Company Size** | | |
| $10M-$50M ARR | 10 | Ideal |
| $1M-$10M ARR or $50M+ ARR | 5 | Potential |
| <$1M ARR | 0 | Not a fit |

**Lead Scoring:**
- **40-50 points**: Highly qualified lead (prioritize)
- **30-39 points**: Qualified lead (follow up)
- **20-29 points**: Potential lead (nurture)
- **<20 points**: Not a fit (deprioritize)
